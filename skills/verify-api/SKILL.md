name: verify-api
description: HTTP API を起動して正常系、異常系、境界値、再起動後を実測する。API を実装または変更した後に使う。
---
1. 受け入れ検査があればそれを使い、新しく作らない。無ければ `acceptance` の形で 1 ファイルに書く。`&`、`cd`、`sleep` をつないだコマンドは承認で止まりやすいので使わない。
2. 起動は `check-kit.mjs` の `start` に任せる。Compose なら README のコマンドで起動し、`start` を書かない。
3. 契約の各項目を、状態コードと本文の両方で確かめる。
4. 保存が要るなら再起動して残るかを見る。
5. 「ID／期待／実測／判定」で失敗を先に報告する。動かせなかったら「未検証」と理由を書き、合格と書かない。
