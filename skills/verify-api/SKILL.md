1. 受け入れ検査があればそれを使い、新しく作らない。無ければ `acceptance` の形で 1 ファイルに書く。`&`、`cd`、`sleep` をつないだコマンドは承認待ちで止まりやすいので使わない。
2. 起動は `check-kit.mjs` の `start` に任せる。Compose なら README のコマンドで起動し、`start` を書かない。
3. 仕様の各項目を状態コードと本文の両方で確認する。
4. 保存が必要なら、再起動してデータが残るかを確認する。
5. 「ID／期待／実測／判定」の形で、失敗を先に報告する。動かせなかったら「未検証」と理由を書き、合格と書かない。
