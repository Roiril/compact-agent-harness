---
name: verify-api
description: HTTP API を起動して正常系、異常系、境界値、再起動後を実測する。API を実装または変更した後に使う。
---
1. 検査を 1 ファイル（`tests/api.check.mjs` など）に書き、`node tests/api.check.mjs` のような単独のコマンドで動かす。`&`、`cd`、`sleep` をつないだコマンドは承認で止まりやすいので使わない。
2. 単体で起動できるサーバーは、検査ファイルが子プロセスで起動し、応答を待ち（上限 60 秒）、最後に必ず止める。Compose なら起動は README のコマンドで行う。
3. 契約の各項目を、状態コードと本文の両方で確かめる。期待は実装ではなく契約から取る。
4. 異常系: 必須項目なし、型違い、壊れた JSON、存在しない ID、空、0、負数、端数、重複。
5. 保存が要るなら再起動して残るかを見る。
6. 「項目／期待／実測／判定」で失敗を先に報告する。動かせなかったら「未検証」と理由を書き、合格と書かない。
